# 宇宙回形针 · 界面设计稿

目标：替换原来那套 1990 年代风格的默认样式，建立符合游戏科幻、宏大主题的视觉语言，并**让视觉随游戏阶段演进**。

## 一句话

**页面中心不是装饰图，而是你正在操作的那个世界。游戏操作直接挂在中心元素上——点中心的对象，两侧换成它的操作与数据。**

| 阶段 | 中心是什么 | 可交互的对象 |
|---|---|---|
| **地球开场** | **公司组织架构图**：人类监管委员会 → 决策核心（AI，画成机房）→ 生产 / 营销 / 资本配置三个部门 | 5 个组织节点 |
| **主宰地球** | **一整颗地球** | 星球上的 5 类设施标记 |
| **太空探索** | **一片宇宙**（亮区＝已探索，暗区＝未知） | 探测器集群 / 物质场 / 漂移者 / 前线 |

## 视觉语言 · 机器视觉

游戏本来就是**一台 AI 的自述**，所以界面就是它的视觉皮层：实景画面 + 识别框 + 读数叠层。

- 识别框（细边框 + 加粗四角 + 标签条）、扫描扫过、脉冲 LIVE 指示灯
- 三阶段是它的三只眼：地球开场（工作台，琥珀）→ 主宰地球（整个地球，橙红）→ 太空探索（深空，紫）
- 阶段配色只换一组 CSS 变量，**同一套素材可以服务多个阶段**

## 几个设计决定

**金融投资部门命名为「资本配置部」。**"配置"正是这个 AI 最终对宇宙做的事——把所有物质配置成回形针。冷冰冰的公司腔调，与游戏内核咬合。

**人类监管委员会画成虚线框**，视觉上区别于公司内部节点。它是唯一"不可操作"的节点——点开只有一句话：信任越高，你能做的事越多，直到不再需要他们的许可。

**决策核心画成机房**：一排指示灯以不同频率闪烁，代表运算活动。它是默认选中的节点，因为**玩家就是它**。

**组织架构的连线是从节点自身锚出的**，不是手写坐标：虚线向下流动表示指令下发，人类监管那一段是反向流动的红色审计线。内容怎么变都不会错位。

**太空的"已探索"是算出来的**：亮区半径 = 满幅 × √0.374 ≈ 61%（按面积换算），由 `--explored` 一个变量驱动。真实实现里把它绑到游戏的探索度字段即可，是**动态**的。

**动效**（全部 CSS / SMIL，无 JavaScript）：组织架构上的数据流动、机房指示灯、选中的节点脉冲、地球上的航线流动与无人机沿航线飞行、星球高光扫过、宇宙前线脉动、探测器由原点向外飞、暗区漂移者游荡、顶栏数字呼吸辉光。

## 怎么看

打开 `index.html` 看总览，点「打开方案」进入 `immersive-core.html`；该文件顶部有「地球开场 / 主宰地球 / 太空探索」切换，可以直接在浏览器里换阶段对比。

单文件自包含（样式内联、图像同目录），双击即可打开，不联网、不需要服务器。

## 落地说明

1. **需要改 HTML 结构**，但**不动任何 `id`，不动 `logic.js`**。游戏逻辑用 `getElementById` 抓元素，只要 id 还在、还在 DOM 里，结构怎么摆都行。
2. **装饰全部靠 CSS。** 识别框、扫描线、引脚、连线都是 `::before` / `::after` 与渐变，不增加 DOM 节点。
3. **图标以 SVG sprite 内联**（`<symbol>` + `<use>`），无额外请求，也没有图标字体的加载闪烁。
4. **游戏自己的显示/隐藏仍然有效。** 逻辑里用 `element.style.display = ""` 表示"显示"、`"none"` 表示"隐藏"。行内样式优先级高于样式表，所以样式表里的 `display: none` 只会在逻辑说"显示"时生效——正好可以拿来做部门的额外筛选，不会把该出现的东西藏掉。

## 素材

`assets/` 是 AI 生成后压缩过的图。`assets/source/` 是原始生成文件，已在 `.gitignore` 中，不需要入库。

生成方式：OpenAI 格式生图接口（凭据在 `image.env`，已加入 `.gitignore`；脚本 `tools/genimg.sh`，`tools/` 同样已忽略）。

`previews/` 是总览页用的缩略图，从设计稿截图压缩而来，改动设计后需重新生成。

## 尚未覆盖

- **窄屏适配**：现在窗口宽度小于 700px 时整个界面被隐藏（`interface.css` 的 `#page { display: none }`）。设计稿按桌面宽度绘制。建议单独一轮。
- **战斗画布**（`<canvas>`）：太空阶段的战斗在设计稿里用静态结算条代替，真实实现需要单独设计 canvas 的绘制风格。
- **解锁过程的动效**：实际游戏里各模块是逐步解锁的，设计稿只画了阶段的代表状态，没有画解锁过程。
